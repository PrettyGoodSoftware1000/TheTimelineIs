# Rule: the MOST SPECIFIC line wins outright (overrides, not multiply).
#   "<Character> scale" beats "Cast scale", which beats "Global scale".
# Global scale covers all art (map, backgrounds, cast). Cast scale covers
# every cast sprite. A character line covers just that character.
# A value of 0 means IGNORE that line, so it falls through to the next level
# up: "Dirtbag scale: 0" uses Cast scale instead. The % sign is optional.
# UI text, buttons, the dialogue box, and the F12 ruler never scale.
# ---------------------------------------------------------------------
# Overlay opacity for the isometric levels: how solid the colour wash is
# INSIDE each highlighted region. The outline around the region is always
# drawn at full strength, so 0% here means "outline only, no fill" - unlike
# the scale lines above, 0 is a real value here and not "ignore this line".
#   Movement - blue, where the selected character can walk
#   Range    - red, how far the armed card reaches
#   Leap     - red, the same for a card carrying Leap (usually a wide area,
#              so it earns a lighter wash)
#   AoE      - purple, a blast card's explosion radius
#   Cone     - purple, a cone card's wedge
#   Guard    - red with skulls, ground somebody is standing guard over
#   Trigger  - violet, an unfired dialogue square
#   Hover    - yellow, the square under the cursor while Ctrl is held
