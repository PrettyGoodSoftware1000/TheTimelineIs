# One block per playable class.
#
# ART is a folder, not a picture. Inside a class's folder each state gets a
# folder of its own holding rotations/ and animations/ — see the README there.
# A class with no such folder yet is drawn as a cube with its initial on top.
#
#   Colour: r, g, b            what colour that cube is
#   Art: FolderName            optional; which state folder to draw from.
#                              Without it, the first folder with rotations in
#                              it is used.
#   Cast Animation: GunShot    optional; an animation folder played over the
#                              sprite while a card is cast
#   Form: Name, Folder, Anim   a shape a shapeshifter can wear: its name, its
#                              art folder, and optionally its own cast
#                              animation. The first Form is where it starts.
#   Card Tags: A, B            optional; which cards it holds. Defaults to the
#                              class's own name.
