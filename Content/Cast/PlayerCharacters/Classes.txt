# One block per playable class.
#
# ART is a folder, not a picture. Inside it a POSE folder (IdlePose) holds the
# pictures and the animation folders — see the README in Content/Cast. Poses
# are found by looking, so nothing here names them. A class with no pose yet
# is drawn as a cube with its initial on top.
#
#   Colour: r, g, b            what colour that cube is
#   Mind: 100                  nerve, or 'Infinite' for something that cannot
#                              be frightened
#   Art: FolderName            optional; which folder to draw from.
#                              Without it, every pose folder is used.
#   Cast Animation: GunShot    optional; an animation folder played over the
#                              sprite while a card is cast. Without it, cards
#                              play SpellCast. A card's own "Animation:" line
#                              beats both.
#   Form: Name, Folder, Anim   a shape a shapeshifter can wear: its name, its
#                              art folder, and optionally its own cast
#                              animation. The first Form is where it starts.
#   Card Tags: A, B            optional; which cards it holds. Defaults to the
#                              class's own name.
