# TURNING. A line naming a FOLDER instead of a .png is a decoration that
# turns: the folder holds one picture per direction, named south-east.png and
# so on, exactly like a card's Projectile Art. The editor rotates it with the
# mouse wheel and writes the direction into the level file beside it.
#

# once that way has been opened. The open picture is this one's name with
# " Open" on the end - Door.png and Door Open.png - and needs no line of its
# own here. Without one the closed picture is faded instead.
