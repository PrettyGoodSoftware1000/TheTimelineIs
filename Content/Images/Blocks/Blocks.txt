# Ground art for the isometric levels.
#
# Family: <name>        groups interchangeable art. The editor offers a family,
#                       then a piece inside it or Random.
# Piece: <file.png>     one image, drawn whole in a single draw.
# Anchor: <x>, <y>      the pixel of that image that lands on the exact centre
#                       of a grid square's top face.
# Scale: <percent>      100 = one image pixel per virtual pixel.
#
# CHECKERBOARD FAMILIES
# Put "Checkerboard Dark:" and "Checkerboard Light:" headings inside a family
# and it stops behaving randomly: which half a square draws from is decided by
# the square's position, so a dark piece never lands beside another dark one.
# Within a half the pieces are still picked at random, so several variants of
# each shade keep the pattern from looking stamped. The piece dropdown does
# nothing for such a family - the grid chooses.
#
#   Family: StoneCheckerboard
#   Checkerboard Dark:
#   Piece: DarkSurface1.png
#   Anchor: 360, 184
#   Scale: 62
#   Checkerboard Light:
#   Piece: LightSurface1.png
#   Anchor: 360, 184
#   Scale: 62
#
# PLACEHOLDERS
# PlaceholderSurface.png is exactly 360x180 - one grid square's top face at
# 1:1 with virtual pixels - so Anchor is its centre and Scale is 100.
# PlaceholderBlock.png is the same face over a 760px body, which is the depth
# DarkStoneSimple1.png draws at. Use them to check that new art lines up.
