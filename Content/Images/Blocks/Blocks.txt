# Ground art that is NOT part of a terrain set: one picture, one square, no
# blending with its neighbours. Terrain sets live in ../Terrain/Terrain.txt and
# are what levels normally use now.
#
# Family: <name>        groups interchangeable art. The editor offers a family,
#                       then a piece inside it or Random.
# Piece: <file.png>     one image, drawn whole.
# Anchor: <x>, <y>      the pixel of that image that lands on the exact centre
#                       of a grid square's top face. A 96x48 surface is
#                       anchored at 48, 24.
# Scale: 100            always 100 here. The line is kept so an old file
#                       still reads; anything else is an error.
#
# CHECKERBOARD FAMILIES
# Put "Checkerboard Dark:" and "Checkerboard Light:" headings inside a family
# and which half a square draws from is decided by its position, so a dark
# piece never lands beside another dark one.
#
# Empty for now: the 128-wide pieces that used to be here were retired when
# the grid moved to 96 and PixelLab became where art comes from.
